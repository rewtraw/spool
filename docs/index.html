An app for your own movie and TV library

Pick something to watch. Spool does the rest.

Tell Spool which movies and shows you want. It finds them, downloads them, files them and plays them on your television, and keeps new episodes coming.

Get started

Set it up on a computer at home.

# with Docker
git clone https://github.com/rewtraw/spool && cd spool
mkdir -p data && $EDITOR compose.yaml   # set the user and your media path
docker compose up -d --build            # http://localhost:7979

# or from source: Rust, Bun, and par2, 7zz and ffmpeg on the PATH
(cd web && bun install && bun run build)
cargo run --release -p spool -- serve

Spool runs on a Mac, a Linux machine or a NAS. It downloads from Usenet, so you need an account with a Usenet provider and an indexer. It starts in a practice mode that changes nothing until you say so. Already using Radarr, Sonarr and SABnzbd? spool migrate brings your library and settings across, and Spool works beside Plex.
